# KAZAKHSTAN TV 🇰🇿 — плагин для Lampa

Раздел внутри Lampa только для сериалов казахстанского производства.
Метаданные и постеры — из TMDB через встроенный TMDB-слой Lampa. Видеопотоков плагин **не содержит** и не добавляет.

## Что внутри

- Кнопка **KAZAKHSTAN TV 🇰🇿** в левом меню Lampa
- 11 категорий: Популярные, Классика, Старые, Новинки, Криминал, Комедии, Драмы, Исторические, Мелодрамы, Семейные, Все сериалы
- Поиск по русскому и оригинальному названию, по году, по названию + году (например `Тест 2020`)
- Кнопка **«Где смотреть (KZ)»** на карточке сериала (официальные сервисы из TMDB Watch Providers)
- Настройки: «Только русскоязычные», «Очистить кеш»

## Установка на Android TV

1. Опубликуйте репозиторий `kazakhstan-tv-lampa` на GitHub (файлы `kazakhstan_tv_lampa.js` и `README.md` в корне, ветка `main`).
2. Ссылка на плагин:
   `https://raw.githubusercontent.com/ВАШ_ЛОГИН/kazakhstan-tv-lampa/main/kazakhstan_tv_lampa.js`
3. В Lampa: **Настройки → Расширения** → добавить плагин → вставьте ссылку → подтвердите.
4. Перезапустите Lampa. В меню появится **KAZAKHSTAN TV 🇰🇿**.

## Как это работает

| Функция | Реализация |
|---|---|
| Списки категорий | встроенный компонент `category_full` (постер, название, год, рейтинг, пульт, пагинация) |
| Данные | `discover/tv` с `with_origin_country=KZ` |
| Ключ TMDB | не хранится в коде: используется `Lampa.TMDB` |
| Поиск | `search/tv` + фильтр по стране KZ, результаты в списке выбора |
| Кеш | поисковые запросы и ответы watch/providers: 1 час, до 40 записей |
| Ошибки сети | уведомление; при наличии старого кеша показывается он |

## Ограничения (честно)

- Данные TMDB по Казахстану неполные. Некоторые категории могут быть пустыми или короткими.
- Фильтр «русскоязычные» использует оригинальный язык в TMDB (`ru`). Русская озвучка казахских сериалов так не определяется. Отключите опцию в настройках, чтобы видеть всё.
- У TMDB нет жанров «История» и «Мелодрама» для сериалов. «Исторические» = War & Politics (10768), «Мелодрамы» = Soap (10766). Менять можно в массиве `CATEGORIES`.
- Результаты поиска показываются списком (без постеров). Постер, описание и число сезонов — на карточке после выбора.
- «Где смотреть» зависит от данных TMDB/JustWatch для региона KZ. Если их нет, плагин так и скажет. Ссылки не выдумываются.
- Открытие внешней ссылки использует `Lampa.Utils.openLink`, если он есть в вашей сборке.
